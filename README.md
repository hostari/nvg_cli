# Rust CLI Starter
A minimal, clean starter for building command-line applications in Rust.
This project provides a simple, well-structured foundation, including argument parsing, basic command handling, and a ready-to-extend project layout.
Ideal for learning, prototyping, or bootstrapping new Rust CLI tools.

[medium](https://medium.com/@grzesiekb/why-clap-provides-the-strongest-basic-functionality-for-create-cli-app-51534dff4f8c)

[linkedin](https://www.linkedin.com/in/grzegorz-bylica/)

1. Add required dependencies in `Cargo.toml`
2. Define and configure CLI arguments in `main.rs`
3. Read input from stdin (piped data) in `main.rs`
4. Parse arguments and execute corresponding actions

Get a working CLI in 15 minutes.  
Polish it in a few hours.
